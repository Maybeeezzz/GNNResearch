# GNN 实验路线：模型 × 优化方法 × 任务

本文件将项目已有实验和后续可规划的比较放入统一分类。它是实验目录/路线规划，不代表所有组合都已实现或测试。本次仅整理文档，未启动训练、基准测试或测试套件。

## 一、三条分类轴

### 1. GNN 模型（骨干）

- **GCN**：图卷积基线；项目包含普通两层 GCN、逐层 SF-GCN，以及图级任务用的稀疏 GCN 编码器。
- **GraphSAGE（SAGE）**：邻居采样/聚合型消息传递骨干；原论文测试，本项目当前官方核心复现矩阵未覆盖。
- **GAT**：注意力消息传递骨干；原论文测试，本项目当前官方核心复现矩阵未覆盖。
- **ResidualGCN**：项目里的深层残差 GCN，用于本地深度探索；不是原论文 ForwardGNN 的原始骨干对照矩阵。

层数、隐藏维度、归一化、残差、预测头、读出方式也属于模型配置。比较优化方法时应固定这些配置；如果 SF 必须使用虚拟节点或局部预测头，应明确记录这是方法必需的组件，不能把它隐藏在“同一个模型”之下。

### 2. 优化/训练方法

| 代号 | 本项目中的含义 | 比较时要注意 |
|---|---|---|
| **BP** | 对任务最终损失进行端到端反向传播 | 常规基线；要报告完整网络更新次数和验证/测试开销 |
| **FF** | Forward-Forward 局部 goodness 学习；节点分类可用 FF-LA（标签拼接）或 FF-VN（虚拟节点） | 经典 FF 用正、负样本/输入训练；负例构造方式和负例数会影响计算与内存 |
| **SF** | Single-Forward / ForwardGNN 逐层局部学习；当前层局部损失更新后冻结，再训练上层 | 每个局部更新不需要 FF 式正、负两路输入；但依然会对当前层损失做梯度更新，不等于“完全不用梯度” |
| **SF-TopDown** | SF 的 top-to-input / top-to-loss 反馈扩展 | 两个信号路径不同，应分别作为方法配置报告 |
| **SF-CE / SF-FF objective** | 链接预测里，在 SF 框架上替换局部目标（如 BCE/CE 或 FF goodness 目标） | “ForwardGNN-FF”在论文链接预测部分是 SF 框架中的目标函数变体，不应误称为经典双前向 FF 算法 |
| **单前向验证复用** | `train.py --method single-forward`：BP 训练复用训练前向结果计算验证损失 | 这是减少验证额外前向的工程策略，不是 ForwardGNN 的 SF 局部学习算法；不得把两个“single-forward”混为一类 |

### 3. 任务类型

- **节点分类**：为节点预测类别；指标通常为 Accuracy、Macro-F1、AUC 等。
- **边预测 / 链接预测**：判断节点对是否有边；常见 ROC-AUC、AP，需要明确负边采样与消息传递图的划分。
- **图分类**：给整张图预测离散类别；例如项目中的 BACE 分子分类。
- **图回归**：给整张图预测连续值；例如项目中的 ESOL 溶解度。
- **其他常见但当前项目未完成的任务**：节点回归、多标签节点分类、边属性分类/回归、图聚类、推荐/关系预测、时序/动态图预测。它们需要各自的标签、划分和评价指标，不能直接套用节点分类结论。

## 三、推荐的后续比较矩阵（尚未执行）

下面是可逐阶段推进的实验路线，不表示本轮已经开跑。先固定任务和划分，再扩展骨干，避免同时改动多个因素后无法归因。

| 阶段 | 任务 | 骨干（固定配置配对） | 方法对照 | 目的 |
|---|---|---|---|---|
| A | 节点分类 | GCN | BP、经典 FF-LA/FF-VN、SF、SF-TopDown | 最直接验证 FF 与 SF；统一数据、划分、层数、隐藏维度、更新预算和计时定义 |
| B | 节点分类 | SAGE、GAT | BP、适用的 FF 变体、SF / top-down SF | 判断结论能否跨消息传递结构迁移；GAT 需单独看注意力开销和缓存是否可用 |
| C | 链接预测 | GCN，之后再扩展 SAGE/GAT | BP、SF-CE/BCE、SF-FF-objective；若要经典 FF 基线，需先明确定义 FF 的正负边输入协议 | 把原论文的 SF 框架目标消融与经典双前向 FF 基线分开回答 |
| D | 图分类、图回归 | 先固定图级 GCN，再扩骨干 | BP、任务适配的 SF、严格定义的 FF | 扩展到图级输出；回归需预先指定连续目标如何用于 FF，不可把离散分箱结果当作原生连续 FF |
| E | 节点回归、边属性预测、聚类、推荐/动态图 | 按任务选择骨干 | BP 与能明确定义的局部/前向方法 | 评估适用边界；每个任务单独定义监督对象、数据拆分及指标 |

### 每条路线的最低对照要求

1. 固定同一数据版本、训练/验证/测试拆分和随机种子；链接预测的正边与负边拆分要防止泄漏。
2. 固定 GNN 主干的消息传递层、深度、隐藏宽度、激活、特征处理和读出；若算法要求额外虚拟节点/标签通道/预测头，单独披露并做相应消融。
3. 同时报告固定更新预算和达到共同验证质量所需的时间；报告 wall-clock、峰值内存、准确性指标及失败/未达标运行。
4. SF、FF、BP 的一步含义不同：记录参数更新数、局部层更新数、正负输入前向次数、完整图前向次数和缓存策略，避免仅按“epoch”作表面公平比较。
5. 超参数选择只看验证集；测试集只作最终一次评估；重复种子不足时把结论称为探索性结果。

## 四、原论文在这套分类中的位置

原论文 *Forward Learning of Graph Neural Networks*（ICLR 2024）位于以下组合：

| 轴 | 原论文覆盖 |
|---|---|
| GNN 模型 | GCN、GraphSAGE/SAGE、GAT；多种骨干并测 1–4 层 |
| 优化方法 | BP 基线；节点分类中 FF-LA、FF-VN 与 SF、SF-TopDown；边预测中 ForwardGNN-CE、ForwardGNN-FF、ForwardGNN-SymBa 等局部目标变体 |
| 任务类型 | 节点分类和链接预测（边存在性预测） |
| 主要指标 | 节点分类 Accuracy、链接预测 ROC-AUC；另有 GPU 内存、节点分类训练时间分析 |

因此，原论文属于“多骨干 × 多前向学习方法 × 节点分类/链接预测”的实验路线。**它不是**图分类或图回归论文，也不能直接证明 SF 在这些图级任务上有效。需特别区分：节点分类部分直接把 FF-VN/FF-LA 与 SF 比较；链接预测部分的 ForwardGNN-FF 是 SF 框架里的 FF 目标变体，不能简单等同于经典 FF 的完整双前向基线。具体设定与边界见[论文总结](forwardgnn_paper_summary.md)。
